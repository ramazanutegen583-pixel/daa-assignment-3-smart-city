# Smart City Infrastructure and Route Planning

Assignment 3 for Design and Analysis of Algorithms.

This Java 17 project models city districts as vertices and roads as weighted edges. It uses graph algorithms to plan infrastructure, check connectivity, and find routes.

## Build and Run

Open `pom.xml` as a Maven project in IntelliJ IDEA and select JDK 17 or later.

The completed project will include demonstrations, correctness tests, and reproducible experiments.
